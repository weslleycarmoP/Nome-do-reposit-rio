# Tela de Login
## Objetivo da Tela e:
ensinar o Usuario a entrar (logar ) no sistema para operar a funcionalidade de caixa

* Como usar o Sistema de login e Senha
* 1.1 na area de trabalho do seu computador procurar o icone do sistema
* 1.2 clicar duas vezes no icone e aguardar para que o sistema seja carregado na tela do seu computador
* 1.3 apos o cadastro do usuario junto a administracao do sistema entrar com o seu usuario e senha
* 1.4 digitar o seu usuario no campo (login) e digitar sua senha no campo ( Digite sua senha)
* 1.5 Caso não consiga logar entrar em contato com o resposvavel pelo seu departamento.
